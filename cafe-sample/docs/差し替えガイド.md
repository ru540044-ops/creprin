# 実際のお店用に直す手順

見本を実際のお店のサイトにするときの作業リストです。上から順に進めれば、半日〜1日で公開できます。

## 1. お店から集める情報

打ち合わせのときに、次の情報をまとめてもらいます。

- 店名（読み方・英語表記）、住所、電話番号、最寄り駅と徒歩の分数
- 曜日ごとの営業時間、ラストオーダー、定休日
- メニューと価格（税込）、テイクアウトできるかどうか、アレルギー（特定原材料8品目）
- 席数、支払い方法、Wi-Fi・電源・駐車場・子ども連れ・ペットの可否
- 写真（外観、店内、人気メニュー3〜5品、季節限定）。スマホで撮ったものでも大丈夫です
- InstagramのURL、Googleマップのお店のURL
- よく聞かれる質問を3〜5個

## 2. 書き換える場所

| 何を | どのファイル | どこを |
|---|---|---|
| 店名・文章・メニュー・価格 | `index.html` | 各セクションの文章をそのまま書き換え |
| 営業時間 | `assets/app.js` | 先頭の `HOURS`（曜日ごとに「開店・閉店・ラストオーダー」を0時からの分で） |
| 営業時間の表 | `index.html` | `#hoursBody` の表と、フッターの営業時間 |
| 混雑の目安 | `assets/app.js` | 先頭の `BUSY`。お店の感覚で0〜100を入れる。使わないならセクションごと削除 |
| 色・文字 | `assets/style.css` | 先頭の `:root`。`--accent`（ボタンの色）と `--kaki`（強調色）を変えるだけで印象が変わる |
| 写真 | `img/` | 同じファイル名で上書き。横長は1600×1000、正方形は1200×1200、`-s` 付きはその半分 |
| 構造化データ | `index.html` | `<head>` 内の `application/ld+json`。店名・住所・電話・営業時間を実際の値に |
| SNS共有の画像 | `img/og.jpg` | 1200×630。外観か看板メニューの写真がおすすめ |

メニューを増やすときは、`<li class="item">` を1つコピーして中身を変えます。テイクアウトできる商品には `data-takeout` を付けると、テイクアウト注文の一覧に自動で入ります。`data-price` には税込価格を数字で入れてください。

## 3. 見本用の表示を外す

- `index.html` の `<meta name="robots" content="noindex,nofollow">` を削除する（検索に出るようにする）
- 画面上部の `.sample-banner` を削除する
- フォームの「デモ」表示（`.demo-note`）を削除する
- フッターの「このサイトはデザインサンプルです」の文章を削除する
- 地図のボタン `#mapLink` の `href` をお店のGoogleマップのURLにして、`aria-disabled="true"` を外す

## 4. 予約と注文を実際に届くようにする

お店の規模と予算に合わせて選びます。

| 方法 | 向いているお店 | やること |
|---|---|---|
| **予約サービスにリンクする** | 予約がそこそこ多い | Airリザーブ、STORES予約、ホットペッパーなどの予約ページへ「席を予約」ボタンをつなぐ。フォームは削除 |
| **Googleフォームに置き換える** | 予約が少なく、とにかく安く始めたい | Googleフォームを作り、ボタンからリンクする。回答はメールで届く |
| **フォーム送信サービスを使う** | 今のデザインのフォームを使いたい | Formspree などのフォーム送信サービスに送る。迷惑送信対策（reCAPTCHAなど）と、個人情報の取り扱いの文章を必ず追加する |
| **LINE公式アカウントにつなぐ** | 常連さんが多い | 「LINEで予約・注文」ボタンにする。お店側はLINEで返信するだけ |

フォームで個人情報（名前・電話番号）を受け取るときは、プライバシーポリシーのページを用意してください。

## 5. 公開する

1. Netlify、GitHub Pages、Cloudflare Pages のどれかにフォルダーごとアップロードする（どれも無料で始められる）
2. 独自ドメイン（例：`yorimichi-coffee.jp`）を使うなら、ドメインを取ってDNSを設定する
3. Googleビジネスプロフィールの「ウェブサイト」欄に、公開したURLを入れる
4. InstagramのプロフィールにURLを入れる

## 6. 公開前のチェック

- [ ] スマホで全ページを上から下まで見て、文字の間違いと表示崩れがない
- [ ] 営業時間・定休日が、Googleマップの表示と同じになっている
- [ ] 電話番号・住所が正しい
- [ ] 予約と注文が実際にお店に届く（テストで1件送って確認する）
- [ ] 写真の掲載について、写っている人の了承を取っている
- [ ] `node tests/check.mjs` が全部通る（営業時間を変えた場合は、テストの期待値も合わせて直す）
