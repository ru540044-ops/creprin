# 料金と提案の仕方の例

この見本を使って、個人経営のカフェに4万円前後で提案するときの例です。金額は目安なので、地域や相手に合わせて調整してください。

## 料金プランの例

| プラン | 料金（税込） | 中身 |
|---|---|---|
| **ライト** | 25,000円 | 見本のデザインそのままで、文章・メニュー・写真・営業時間を差し替え。予約はGoogleフォームか予約サービスへのリンク |
| **スタンダード（おすすめ）** | 40,000円 | ライトに加えて、色をお店に合わせて調整、テイクアウト事前注文と予約フォームを実際に届くように設定、Googleビジネスプロフィールとの連携、公開作業まで |
| **月額サポート** | 月3,000円〜 | メニューや季節限定の差し替え（月2回まで）、臨時休業のお知らせ、表示崩れの修正 |

ドメイン代（年1,000〜3,000円程度）と、予約サービスを使う場合の利用料は、お店の負担にするのが一般的です。最初に伝えておくと、あとで揉めません。

## 4万円の価値として伝えること

作業の量ではなく、**お店の困りごとがどう減るか**で説明します。

- **電話やDMでの予約対応が減る**：前日までの予約はフォームで受けられる。定休日やモーニング時間の予約は自動ではじく
- **テイクアウトで待たせない**：受け取り時間を選んで事前に注文してもらえるので、朝の混雑時にレジが詰まりにくい
- **「今やってる？」がすぐ分かる**：営業中かどうか、今日の営業時間、混みやすい時間が開いてすぐ見える
- **AI検索やGoogleで見つけてもらうための土台**：営業時間・住所・設備を、検索エンジンやAIが読み取りやすい形（構造化データ）でも書いている
- **アレルギーの質問に答えやすい**：特定原材料8品目を、メニューごとに表示できる

「必ず検索の上位に出る」「必ずお客さんが増える」とは言わないでください。言えるのは「見つけてもらいやすく、予約しやすくする」までです。

## 見せ方

1. 見本のURLをスマホで開いて、お店の人に**自分で触ってもらう**（下のメニューから「席を予約」「持ち帰り」を試してもらうと伝わりやすい）
2. 「このお店の名前とメニューに変えた見本を、無料で作ってお持ちします」と提案する
3. お店のInstagramの写真とメニューを借りて、見本を差し替えて見せる（公開はしない。見せ終わったら消す）
4. 気に入ってもらえたら、料金と納期（目安：材料がそろってから1週間）を伝える

## 契約のときに決めておくこと

- 料金と支払い方法（着手時に半額、公開時に残り半額がおすすめ）
- 修正の回数（例：公開前の修正は2回まで無料）
- 写真や文章はお店が用意するのか、こちらで撮る・書くのか
- 公開後の更新は誰がやるのか（月額サポートにするか）
- サイトのデータの持ち主（納品後はお店のものにするのが一般的）
