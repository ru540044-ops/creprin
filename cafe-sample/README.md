# ヨリミチ珈琲 — カフェのWebサイト見本

架空のカフェ「ヨリミチ珈琲」のWebサイトです。個人経営のカフェや喫茶店に見せる**営業用の見本**として作りました。店名・住所・電話番号・メニュー・価格・画像はすべて架空です。実在の店舗とは関係ありません。

元にしたのは、建設会社の採用サイト見本（`takajo-recruit-final.zip`）です。業種に合わせて中身はすべて作り直し、次の作り方だけを引き継いでいます。

- HTML・CSS・JS を分けて、外部ライブラリなしで動く（フォントだけ Google Fonts）
- 見本であることを画面上部と各フォームに表示する（誤解を防ぐため）
- `noindex` を設定して検索に出ないようにする
- 実ブラウザでの動作テストを付ける

## 開き方

フォルダーごと静的ホスティング（Netlify、GitHub Pages、Cloudflare Pages など）に置くと、そのまま公開できます。

パソコンで確認するだけなら `index.html` をブラウザで開いてください。スマホで見せるときは、公開したURLを開くのが確実です。

## できること

| 機能 | 内容 |
|---|---|
| 営業中の表示 | 日本時間で「営業中・18:00まで」「本日定休日・明日 7:30から」などを自動で表示 |
| メニュー | コーヒー／ドリンク／フード／焼き菓子のタブ。点線でつないだ値段表。アレルギー表示（特定原材料8品目）の切り替え |
| 秋の限定 | 季節メニューの紹介（季節ごとに差し替える前提） |
| テイクアウト事前注文 | テイクアウトできる商品だけを自動で並べ、数量・合計・受け取り日時を選べる。定休日と締め切り後の時間は出ない |
| 席の予約 | 前日まで・30日先まで・10:30以降・定休日を除く、などの条件をチェック。確認画面を経て完了画面へ |
| 混雑の目安 | 平日／土日祝の時間帯ごとの混み具合を棒グラフで表示 |
| アクセス | 簡単な地図、今日の営業時間に印、電話番号のコピー |
| よくある質問 | ひとり客、子ども連れ、パソコン作業、豆の購入、ペット |
| スマホ用の下部メニュー | メニュー／持ち帰り／席を予約／アクセス |
| AI検索・Google向けの情報 | 構造化データ（`CafeOrCoffeeShop`）で営業時間・住所・設備を記述 |

**注文と予約は送信されません（デモ）。** 本番では予約サービスやメール通知とつなぎます。手順は `docs/差し替えガイド.md` にあります。

## ファイル

```
index.html            ページ本体（メニューや文章はここに直接書いてある）
assets/style.css      デザイン（色・文字はファイル先頭の :root で一括変更）
assets/app.js         動き（営業時間は先頭の HOURS だけ書き換える）
assets/favicon.svg    タブのアイコン
img/                  画像（*-s.webp はスマホ用の小さい版）
tools/make_images.py  見本用イラストの生成スクリプト
tests/check.mjs       実ブラウザでの動作テスト（55項目）
docs/差し替えガイド.md  実際のお店用に直すときの手順
docs/販売プラン.md      料金と提案の仕方の例
docs/screenshots/     PC・スマホのスクリーンショット
docs/test-results.json テストの結果
```

## テスト

Chromium と Playwright を使います。

```sh
node tests/check.mjs                 # 55項目のチェック
SHOTS=1 node tests/check.mjs         # スクリーンショットも保存
```

営業中の判定、受け取り時間、予約の入力チェックは日付を固定してテストしています。画面のテストはスマホ（390px）とPC（1280px）の両方で、横スクロールが出ないこと、注文と予約が最後まで進むこと、JavaScriptのエラーが出ないことを確認します。

## 画像について

`img/` の画像は `tools/make_images.py` で描いたイラストです。実際の料理や店内の写真ではありません。本番では必ずお店の写真に差し替えてください。
