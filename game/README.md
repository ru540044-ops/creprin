# NEON BAY

GTA 風のトップダウン型オープンワールド・クライムアクションを、ブラウザ向けにゼロから作ったゲームです。
外部ライブラリや画像・音声ファイルは使っていません。グラフィックは Canvas 2D、サウンドは WebAudio で全部コードから生成しています。

> 名前・街・キャラクターはすべてオリジナルです。既存の作品とは関係ありません。

## 遊び方

`game/index.html` をブラウザで開くだけで遊べます（ビルド不要）。

```sh
cd game && python3 -m http.server 8000   # → http://localhost:8000
```

### 操作（PC）

| キー | 動作 |
| --- | --- |
| WASD / 矢印 | 移動・運転 |
| マウス | 照準、クリックで射撃（車からも撃てる） |
| F / E | 車に乗る・降りる（運転中の車ならカージャック） |
| Space | ハンドブレーキ（ドリフト） |
| Shift | ダッシュ |
| Q / ホイール / 1-5 | 武器切替 |
| R | ラジオ局を変える |
| H | クラクション |
| M | 全体マップ |
| Esc / P | ポーズ |

### スマホ版

縦向き・横向きのどちらでも遊べます（横向きがおすすめ）。

| 操作 | 動作 |
| --- | --- |
| 画面の左半分 | 指を置いた所がスティックになる：移動・運転 |
| 画面の右半分 | ドラッグで照準して射撃（照準アシスト付き）、タップで自動照準射撃 |
| 乗る / 降りる | 車の近くでボタンが光ったら乗車（運転中の車ならカージャック） |
| FIRE | 自動照準で連射 |
| ブレーキ | ハンドブレーキ（運転中だけ表示） |
| 武器 / MAP / RADIO / II | 武器切替・地図・ラジオ・ポーズ |

- 被弾・衝突・爆発で振動（対応端末のみ）
- 開始時にフルスクリーン化、アプリを切り替えると自動ポーズ
- **ホーム画面に追加**するとアプリとして起動し、一度読み込めばオフラインでも遊べる（PWA。https か localhost で配信したとき）
- 処理が重い端末では自動で描画解像度を下げる

## 主な機能

- **街**: 8×8 ブロックの街、ビーチ、海。ダウンタウンの高層ビル、公園、駐車場、病院、警察署。疑似 3D のビル描画と影
- **車**: 6 車種（コンパクト、セダン、スポーツ、タクシー、バン、パトカー）。ドリフトする車の挙動、衝突、ダメージ、炎上、爆発
- **交通 AI**: 車線を守って交差点で曲がる車、歩道を歩いて横断歩道を渡る歩行者。銃声や事故でパニックになる
- **戦闘**: 素手、ピストル、SMG、ショットガン、ロケットランチャー。車からの撃ち合いもできる
- **指名手配（★1〜5）**: パトカーの追跡、警官の降車と発砲、★4 以上でヘリが来る。警察の視界から逃げ切るか、塗装屋（$300）で手配度が消える。WASTED / BUSTED あり
- **ミッション**: 3 人の依頼人（地図の Ⓜ）から「運び屋」「ストリートレース」「始末屋」「車泥棒」を受けられる。進めるほど難しくなり、報酬も上がる
- **昼夜サイクル**: 夕焼け、街灯、ヘッドライト、窓明かり、ネオンサイン
- **その他**: カーラジオ（シンセウェイヴ／ハウスを自動演奏）、ミニマップ、エリア名表示、お金と進行の自動セーブ（localStorage）

## ファイル構成

```
game/
├── index.html      タイトル・ポーズ・タッチ操作 UI
├── style.css
├── manifest.webmanifest / sw.js / icons/   PWA（ホーム画面追加・オフライン）
└── js/
    ├── core.js     ユーティリティ・入力
    ├── audio.js    効果音・エンジン音・サイレン・ラジオ（WebAudio）
    ├── world.js    街の生成・地面のプリレンダリング・衝突判定
    ├── render.js   描画・ライティング・HUD・マップ
    ├── game.js     車・歩行者・AI・戦闘・警察・メインループ
    ├── missions.js ミッション
    └── mobile.js   スマホ版（タッチ操作・振動・フルスクリーン）
```
